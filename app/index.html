簡易マニュアル Quick Manual
計測
端末を固定し、開始 で計測開始。停止 または 自動停止 で終了します。
Measurement
Stabilize the phone, then press Start. Stop with Stop or Auto-stop.
波形 / スペクトル
時間波形の |mag| は sqrt(X^2 + Y^2 + Z^2) です。スペクトルのベクトル成分は PSD_X + PSD_Y + PSD_Z として端末の向きに依存しにくくしています。FFT はPSD、1/3オクターブは帯域RMSを表示します。成分は下のチェックで切替でき、波形は時間範囲、スペクトルは周波数範囲を指定できます。
Waveform / Spectrum
The time waveform uses sqrt(X^2 + Y^2 + Z^2) for |mag|. The spectrum vector is PSD_X + PSD_Y + PSD_Z, making it less dependent on device orientation. FFT shows PSD, while 1/3 octave shows band RMS. Use the checkboxes to select components and set the time or frequency range.
サンプリング品質
実測周波数、ジッター、欠損、最大ギャップ、分解能を確認できます。「低品質」または「データ不足」の場合は、誤解を招く周波数結果を避けるためスペクトルを表示しません。
Sampling quality
Review the measured rate, jitter, estimated loss, maximum gap, and resolution. The spectrum is hidden for Poor or Insufficient records to avoid misleading frequency results.
拡大表示
拡大 でグラフを全画面に拡大できます。
Zoom
Use Zoom to view charts in full screen.
エクスポート / インポート
CSV/分析JSON/ZIP/再取込用JSONで保存できます。復元にはZIPまたは再取込用JSONを使用してください（分析JSONは再取込できません）。保存先はブラウザ/OSに依存し、アプリ側から指定できません。インポートはファイル選択で選んだもののみ読み込みます。
Export / Import
Save as CSV, analysis JSON, ZIP, or importable JSON. Use ZIP or importable JSON to restore data; analysis JSON cannot be imported. The save location is controlled by the browser/OS, not the app. Import only reads the file you select.
